# Registros da versão 1

**Autores:** José Kaike Gomes dos Santos e João Manoel da Silva Oliveira

A primeira versão do HemoFlow controlava bolsas de sangue dentro de um hemocentro. Depois da avaliação do projeto, mudamos o foco para a captação e o retorno de doadores, e assim nasceu a versão 2.

Guardamos aqui os registros daquela fase, sem alterar os resultados, para mostrar a evolução do projeto:

- [relatorio-auditoria.md](relatorio-auditoria.md): auditoria técnica de 10/11/2026;
- [relatorio-testes.md](relatorio-testes.md): registro dos testes da versão 1;
- [roteiro-apresentacao.md](roteiro-apresentacao.md): roteiro da primeira apresentação.

Alguns nomes de arquivo citados nesses textos mudaram depois. Cada documento traz no começo a lista com os nomes atuais.
